# 03: Studio 비밀값 칸·막힘 표시·내보내기

**What to build:** 세션 패널 "비밀값"(이름·값, 값은 작업 프로세스 메모리에만, 화면에는 이름만). 넣으면 목표에 자리표시를 덧붙인다(러너 규칙: 목표에 주어진 비밀값만 쓴다 — 내보낸 테스트·녹화 키와 같은 문장). 세션 시작에 값 전달(IPC 검사: 이름 규칙·길이·개수). 결과가 blocked 면 사유와 필요한 이름을 보이고 칸에 채운다. 결정적 내보내기: enter_secret 은 입력칸이면 `type(secret())`, 키패드면 `screen.tapKeys(secret())`. 실기 확인(간편비밀번호 화면의 키패드에 글자가 있는지 먼저 본다).

**Blocked by:** 01, 02

**Status:** ready-for-agent
