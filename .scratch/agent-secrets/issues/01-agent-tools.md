# 01: 에이전트 툴 blocked·enter_secret, 반복 고리 감지

**What to build:** (실기 Studio 세션에서 앱 중간 간편비밀번호 화면에 막혀 20턴을 헛돎 — 2026-11-14)
- `blocked(reason, secret)`: 목표에 없는 비밀값이나 사람만 할 단계(본인인증·캡차·생체)를 만나면 지어내지 않고 멈춘다. 결과 `blocked: { reason, secret? }`.
- `enter_secret(ref, name)`: 목표에 자리표시가 주어진 비밀값을 넣는다. ref 가 입력칸이면 그대로 입력, 아니면 키패드: 값의 글자마다 지금 화면을 다시 보고 그 글자가 이름·글자인 키를 탭(섞이는 보안 키패드). 값은 모델·기록·오류에 나오지 않는다. 키를 못 찾으면 "n번째 글자의 키 없음(글자 숨김)".
- 녹화: `enter_secret` 액션(text 에 자리표시) — protocol CACHE_TOOLS 계약 먼저. 재생도 같은 방식.
- 반복 고리: 길이 2~4 의 같은 호출 묶음이 세 번 연달아면 모델에게 알리고, 네 번이면 멈춘다.
- 시스템 프롬프트: 값을 지어내지 말고 blocked.
