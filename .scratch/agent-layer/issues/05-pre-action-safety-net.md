# 05: 액션 전 안전망 — 모델이 고른 대상이 실행 순간에도 같은 대상인지 확인한다

**What to build:** 모델이 "이 버튼을 탭" 을 고른 때와 엔진이 실제로 탭하는 때 사이에 화면이 바뀌면(로딩·목록 갱신·팝업) 엉뚱한 곳을 누른다. 에이전트는 툴 호출마다 대상의 설명(역할·이름·텍스트·위치·주변 노드의 트리 조각)을 남기고, 실행 직전에 화면을 다시 보아 가중치 재탐색으로 같은 대상을 찾는다. 찾으면 그 ref 로 실행하고, 못 찾거나 애매하면 실행하지 않고 그 턴을 다시 묻는다. 픽셀 비교(대상 영역의 변화)는 선택 단계로 켤 수 있다.

**Blocked by:** 01 (agent.act 골격)

**Status:** done

- [x] 픽셀 비교는 엔진이 픽셀을 줄 때만, 설정으로 켠다(기본 꺼짐)
