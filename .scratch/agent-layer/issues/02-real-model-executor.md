# 02: 실제 모델 실행기 — Claude API 가 StepExecutor 뒤에서 툴을 고른다

**What to build:** 같은 `agent.act` 가 실제 모델(Claude, 기본 Sonnet 5.5, 설정으로 Opus 5.5·Haiku 5.5)로 돈다. API 키는 환경변수로만 받고 로그·이벤트·증거 어디에도 남기지 않는다. 사내망(SSL 인터셉션)에서도 호출된다. 스텝에는 호출 수와 토큰 사용량이 남아 Console 이 비용을 볼 수 있다.

**Blocked by:** 01 (agent.act 골격)

**Status:** ready-for-agent

- [ ] 모델·기한·재시도(일시 오류만)·최대 토큰은 설정(환경변수와 러너 옵션), 기본 Sonnet 5.5. 키가 없으면 act 는 분명한 설정 오류로 실패(테스트를 엉뚱하게 실패시키지 않음)
- [ ] 01 의 action spec 에서 만든 툴 스키마를 그대로 모델의 tool 정의로 쓴다(따로 적지 않는다)
- [ ] 스텝 이벤트에 토큰 사용량(입력·출력, 캐시 적중이 있으면 그것도). 이벤트 스키마를 바꾸면 protocol 계약 테스트를 먼저 갱신
- [ ] 개인정보·비밀: 가짜 HTTP 서버로 요청 본문을 가로채 secure 값·API 키가 없음을 확인. 화면 이미지(픽셀)를 보낼지는 설정(기본: 트리만)
- [ ] 사내망: `NODE_EXTRA_CA_CERTS` 로 동작함을 문서화하고 확인
- [ ] 키가 있을 때만 도는 opt-in 테스트로 FakeEngine 로그인 시나리오를 실제 모델이 끝냄(호출 수·토큰 기록)
