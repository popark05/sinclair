# 04: 비밀값 — 모델은 자리표시만 보고, 러너가 입력할 때 바꾼다

**What to build:** 테스트가 `agent.act(\`아이디 qa, 비밀번호 ${secret('QA_PASSWORD')} 로 로그인\`)` 처럼 비밀값을 넘기면, 모델은 `{{secret:QA_PASSWORD}}` 같은 자리표시만 보고 그것을 입력하라는 툴 호출을 낸다. 실제 값은 러너가 엔진에 입력하는 순간에만 바꿔 넣는다. 비밀값은 프롬프트·모델 응답·스텝 이벤트·아티팩트·로그 어디에도 남지 않는다(intent 의 제약 "모델이 비밀값을 보지 못해야 한다").

**Blocked by:** 01 (agent.act 골격)

**Status:** ready-for-agent

- [ ] `secret(이름)` 은 실행 환경(환경변수 또는 비밀 저장소 어댑터)에서 값을 찾고, 없으면 분명한 설정 오류
- [ ] 모델에 가는 모든 텍스트(목표·관찰·지난 턴)에는 자리표시만. 입력 툴의 인자에 자리표시가 오면 러너가 치환해 엔진에 넘긴다. 자리표시를 다른 툴(탭 등)·다른 필드에 쓰면 거부
- [ ] 입력한 필드는 화면 관찰에서 secure 로 다뤄지지 않더라도 그 값을 관찰·요약·아티팩트에서 지운다(값 일치로 가림)
- [ ] 스텝 instruction·이벤트·스크린샷 아티팩트 메타·로그에 값이 없음을 테스트(대본 모델 + 02 가 있으면 가짜 HTTP 로 요청 본문까지)
