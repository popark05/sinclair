# 07: Ledger 컨텍스트 관리 — 긴 act 세션도 토큰 예산 안에서 돈다

**What to build:** act 세션이 길어지면 지난 턴의 관찰·툴 호출이 쌓여 토큰이 커지고 비용·지연이 는다. 에이전트는 턴 기록을 영역(목표·최근 턴 전체·오래된 턴 요약·현재 관찰)으로 나누어 관리하고, 예산을 넘으면 오래된 턴부터 요약으로 바꾼다. 긴 세션에서도 요청 크기가 상한을 넘지 않고, 목표와 최근 맥락은 잃지 않는다.

**Blocked by:** 02 (실제 모델 실행기)

**Status:** ready-for-agent

- [ ] 영역과 예산(토큰 추정 방법, 기본 예산과 이유 주석), 넘을 때 줄이는 순서
- [ ] 오래된 턴 요약은 결정적 요약(툴 호출·결과 한 줄) 우선, 모델 요약은 설정으로
- [ ] 관찰은 최신 것만 전체로, 이전 관찰은 바뀐 부분 요약
- [ ] 테스트: 대본 모델로 턴 50개 세션에서 매 요청의 추정 토큰이 예산 이하, 목표 문장과 최근 턴이 항상 들어 있음; 02 의 사용량 기록과 비교
