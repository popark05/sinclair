# 01: 화면 개인정보 가림 — 모델과 기록에는 화면의 이메일·전화번호·이름이 남지 않는다

**What to build:** 에이전트가 모델에 보내는 화면 글자(act 관찰·판정 관찰·화면 변화·요약 모델 입력)와 러너가 남기는 기록(스텝 이벤트·테스트 오류·screen-tree 아티팩트)에서 개인정보를 종류 자리표시(`<이메일>`, `<전화번호>`, `<개인정보>` …)로 바꾼다. 패턴으로 찾는 것(이메일·전화번호·주민등록번호·카드번호·IMEI)은 자동, 이름·계정명처럼 패턴으로 못 찾는 것은 `SINCLAIR_AGENT_PII_TERMS` 목록으로 받는다. 기본 켜짐, `SINCLAIR_AGENT_PII=off` 로 끈다. 2026-11-09 실기기 실행에서 설정 첫 화면의 소유자 이름·계정 이메일이 모델에 간 것이 계기.

**Blocked by:** agent-layer 01~08(완료)
