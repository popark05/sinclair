# 0002. EverMock은 별도 앱으로 유지하고 디바이스 레이어만 공유한다

- 상태: 승인
- 날짜: 2026-11-07

## 맥락
Studio와 EverMock을 합칠지 분리할지 결정해야 했다. 두 앱이 각자 기기를 잡으면 USB 인터페이스 점유가 충돌한다.

## 결정
분리 + 패키지 공유. 디바이스 레이어를 `packages/device-layer`로 뽑아 하나의 데몬이 기기를 소유하고, Studio는 EverMock의 프록시·시나리오를 fixture로 호출한다.

## 결과
EverMock 안정성을 담보로 잡지 않고, 나중에 합치기로 해도 비용이 작다.
