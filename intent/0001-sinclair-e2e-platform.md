# 0001. Sinclair E2E 검증 플랫폼

- 상태: 초안
- 작성: 2026-11-07
- 관련 spec: specs/0001-architecture.md

## 문제

모바일 앱 QA가 수동 조작과 기기별 반복에 묶여 있다. 기존 자동화(Appium 류)는 스크립트 작성·유지 비용이 높고, 에이전트형 도구(artemis 등)는 결과가 비결정적이라 회귀 검증에 쓰기 어렵다. 실행 결과도 개인 로컬에 흩어져 릴리즈 단위 검증 현황을 한눈에 볼 수 없다.

## 기대 결과

- 자연어 목표로 한 번 탐색한 흐름을 검증 통과 후 결정적 스크립트로 굳혀, 이후 실행은 모델 호출 없이 재생된다.
- 릴리즈 빌드와 기기 매트릭스를 지정한 Cycle을 실행하면 TestCase × 타깃 매트릭스와 Verdict(통과/실패/블록/플래키)가 자동 집계된다.
- EverMock 시나리오를 테스트에서 선언적으로 지정해 500·타임아웃 같은 엣지 케이스를 재현한다.

## 영향받는 사용자와 시스템

- QA 엔지니어(테스트 작성·디버깅, Studio 사용)
- 릴리즈 담당·팀장(Console에서 현황 확인)
- 사내 CI, EverMock, 기기 플릿(맥 미니에 USB 연결된 Android/iOS)

## 제약

- 사내망 SSL 인터셉션 환경에서 빌드·설치가 되어야 한다.
- `reference/`의 FSL 라이선스 코드(mobilecli, devicekit)는 설계만 참고한다.
- 설치된 macOS/Windows 빌드에서 동작해야 한다(dev 모드만으로 검증 금지).
- 모델이 비밀값(계정, 토큰)을 보지 못해야 한다.

## 성공 기준

- 샘플 앱의 핵심 플로우 10개를 에이전트로 작성해 결정적 스크립트로 굳히고, 재실행 시 모델 호출 0회로 통과.
- Cycle 1회로 Android 2대 + iOS 1대 매트릭스 결과가 Console에 집계.
- 플래키 테스트가 자동으로 표시되고 waive 가능.
